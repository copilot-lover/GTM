# Orbit Frontend

React + Vite + TypeScript + Tailwind dashboard and dialer. Scaffolded in
Phase 3 (Dashboard & CRM UX) per the master spec; dialer module in Phase 4
follows `Daddy Dialer - Lovable Prompt.txt` as its requirements doc.

Visual direction (spec §13): dark-industrial theme — near-black surfaces,
neon green accents (#22C55E), Inter UI font, JetBrains Mono for data,
dense tables.
